# Think Mybiz Accountants website — source

This repo **is** the live site. `main` deploys to `public_html` on thinkmybiz.co.za (Hostinger Git deployment). Never upload files manually in hPanel.

## Editing pages

All HTML pages, `sitemap.xml`, `robots.txt` and `.htaccess` are generated by `_src/build.py`. Do not hand-edit generated `index.html` files: edit `build.py` and rebuild.

```bash
python3 _src/build.py      # regenerates every page at the repo root
git add -A && git commit -m "…" && git push   # push to main = live
```

Hand-edited files (not generated): `assets/css/style.css`, `assets/js/main.js`, `contact.php`, `assets/img/*`.

`/_src/` is blocked from public access by `.htaccess`.

## Insights (articles)

Articles live in `_src/articles/*.md` (format in `_src/articles/README.md`). The build turns each into `/insights/<slug>/` with Article structured data, adds it to the Insights index, the home page, the related service page, the sitemap and `/insights/feed.xml`. The Insights menu item appears once at least one article is published.

Publishing is approval-gated: new articles arrive as pull requests on a branch; merging the pull request into `main` publishes them.

`_src/lastmod.json` records when each page's content last changed (used for `<lastmod>` in the sitemap). Commit it with every build.

## Settings in build.py

- `WHATSAPP` — WhatsApp number 066 210 5631 (confirmed by MF Banda 20/11/2026). Set to "" to hide WhatsApp buttons.
- `SOCIAL` — social media profile URLs; each filled one shows as a footer icon and in the business details for Google.
- `OPENING_HOURS` — e.g. `["Mo-Fr 08:00-17:00"]` once confirmed.
- `GA_ID` — Google Analytics 4 measurement ID. When set, a cookie-consent bar appears and analytics load only after Accept; enquiries (`generate_lead`), call, WhatsApp and email clicks are tracked as events.
- `GSC_VERIFY` — Google Search Console HTML-tag verification code.
- Contact details, practitioner number and address are constants at the top of the file.

The build stops with an error if any page title is over 60 characters or a description over 160.

## Contact form

`contact.php` emails enquiries, then sends the enquirer a one-off acknowledgement (set `$ACK_ENABLED = false` to stop it). It emails enquiries to accounts@thinkmybiz.co.za (From and To: accounts@thinkmybiz.co.za, an existing mailbox; Reply-To: the enquirer). Nothing is stored on the server. If the PHP handler is unreachable, the form falls back to opening the visitor's email app.

## Lead system and practice portal (added 23 Nov 2026)

| Part | Where | What it does |
| --- | --- | --- |
| Lead register | `contact.php` + `inc/core.php` | Every enquiry is emailed **and** saved with a reference (TMB-yymmdd-XXXX) and its source (UTM / referrer / landing page). Email delivery never depends on the database. |
| Private data | `../.tmb-data/tmb.sqlite` (outside `public_html`, outside Git) | Leads, notes, visit statistics, subscribers, settings, audit log. Created automatically. Backed up with the hosting account; the portal also offers a download. |
| Visit statistics | `api/t.php`, `assets/js/main.js` | Cookieless page views, time on page, lead actions. No IP stored (daily-rotating salted hash). Respects DNT / GPC. Bots ignored. |
| Alerts sign-up | `api/subscribe.php`, `confirm.php`, `unsubscribe.php` | Double opt-in list for SARS deadline alerts. |
| Portal | `/portal/` | Dashboard, lead pipeline and follow-ups, email replies (templates + AI drafts), tracked campaign links with QR codes, social post drafts (Facebook Page publishing optional), subscribers, settings, audit log. |
| Daily summary | `portal/cron.php` (hosting cron, 07:00) | Emails new leads, follow-ups due and yesterday's traffic to the practice mailbox. |

Security: one-time setup/reset links go only to the practice mailbox; passwords hashed; optional TOTP two-step sign-in; login rate-limited; CSRF on every form; strict CSP; session idle timeout 1 hour; `/inc/` blocked; portal and API send `noindex`.

Nothing is sent to a client or posted to social media unless the practitioner clicks the button. AI output is a draft only.

Advertising tags (`GA_ID`, `META_PIXEL`, `LINKEDIN_PARTNER` in `build.py`) load only after cookie consent.

### Reusing for another practice

1. Copy the repository.
2. Change the constants at the top of `_src/build.py` (name, contacts, addresses, services) and `inc/config.php`.
3. Replace the logo files in `assets/img/` and rewrite the articles in `_src/articles/`.
4. Build, deploy, open `/portal/` and use "Email me the link" to set up the owner account.
